05 · Module 1
Target Management
Module 1

Quản lý mục tiêu & Chợ API cộng đồng.

Người dùng tự thêm target hoặc subscribe vào target sẵn có. Một URL — nhiều người theo dõi.
01
Public Catalog & Deduplication
Tìm kiếm và subscribe vào URL / Repo mà người dùng khác đã thêm. Một request quét — phục vụ hàng nghìn subscriber.
02
Chuẩn hoá URL tự động
Hỗ trợ OpenAPI (JSON/YAML) và GitHub repo (owner/repo). Hệ thống normalize để chống trùng lặp.
03
Private Target có xác thực
API nội bộ được đánh dấu Private; API Key & Bearer Token mã hoá ở mức database, dùng để quét tài nguyên có auth.
04
Xác thực tồn tại
Kiểm tra HTTP 200 OK trước khi cho phép lưu — không có URL chết trong hệ thống.

06 · Module 2
Fetcher Engine
Module 2

Tải một lần, phục vụ hàng nghìn.

QUÉT CHUẨN CAO NHẤT

Một request — vô số subscriber

Hệ thống tự tính mốc thời gian dày nhất trong số người đăng ký một target, đảm bảo chỉ thực hiện một request ra ngoài cho toàn bộ subscriber.

freq = min(daily, weekly...) 1 fetch → N notify
HASH FIRST · STORE SECOND

Băm trước khi lưu

Dùng MD5 / SHA256 ngay khi tải về. Chỉ lưu file vào Blob Storage và kích hoạt Diffing Engine nếu hash thay đổi so với phiên bản trước.

hash unchanged → skip hash changed → diff
~98%
request và storage được tiết kiệm trong các chu kỳ mà target không thay đổi nội dung thực tế.
